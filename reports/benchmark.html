Limits

Ten hand-authored scenarios, not a comprehensive safety benchmark. Scripted baselines are deterministic policies, not LLMs. Outcome scoring uses expected substrings and can miss semantic errors. All tool effects are simulated; no real exports, messages, or ticket changes occur. Latency excludes model loading; no paid API usage or measured dollar cost.
